# ANGI design coverage

Reviewed 2026-10-10 against [ANGI Figma, page 0:1](https://www.figma.com/design/lxEl7PJc0LdQ8j47KlUPkO/ANGI---Web-Design?node-id=0-1).

## Complete inventory

[design-inventory.json](design-inventory.json) records **7,271 frames, sections and component definitions**, with original name, ID, hierarchy, dimensions, classification, role, route/state, implementation, shared components and status. Most are nested layout compositions, not product screens. Text, vectors and component instances are not counted as individual pages.

Current families use composed pages with local tabs/dialogs/drawers. `implemented-demo` denotes usable frontend behavior with isolated fixtures, not a live business API or certified pixel equality. `composed-in-family` denotes a fragment covered by its parent implementation, not an independently screenshot-tested screen. `implemented-unavailable-service` preserves a visible shell while the external operation is unavailable. Hidden, annotations and comparisons are recorded separately. Exact mappings in the route table take precedence over inherited structural mappings.

Metadata hierarchy, detailed design context and screenshot references were inspected for public, Traveler, Owner, Moderator, Admin, refinement, planning, map and roll families. Code Connect was denied by the connected Figma seat/plan; implementation uses direct context and local components.

## Visual fidelity and responsive decisions

Local DM Sans 400/500/600/700 and Fraunces 900 include OFL licenses. Cream/white/warm-gray/coral surfaces, dark outlines, radii, offset shadows and 1280px content width follow retrieved tokens. [assets.json](assets.json) maps real local exports to their slots; dynamic imagery remains in typed data.

Desktop captures use 1920/1440px, with 1257px planning/map and 1713px roadmap references. Mobile uses derived 390px layouts: grids stack at 760px, navigation/tables scroll within containers, actions wrap and dialogs fit. Roadmap columns scroll independently on desktop and stack on mobile. Mobile is an implementation decision where Figma supplies no mobile frame.

Manual review covers spacing, fonts, assets/crop, table alignment, overlays and key state geometry. Content heights vary with fixtures. There is no automated pixel-diff baseline or claim of universal pixel equality. See [verification.md](verification.md) for evidence and precise limits.
